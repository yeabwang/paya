# Model artifacts

`paya-best.pt` is the verified selected checkpoint. Binary weights and `export/` are ignored by Git. The complete inference bundle is published privately at [yeabwang/Paya](https://huggingface.co/yeabwang/Paya).

See [the model card](model.card.md), [checkpoint identity](checkpoint.json) and [results](../results.md). Download the complete bundle into `models/export/` to use `paya.inference.load_model`.
